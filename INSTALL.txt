WHAT THIS FILE DOES
This replaces the existing GitSkins auto-detected language spectrum with one unified technology panel in the same visual style: dark navy surface, monospaced typography, spaced heading, dashed separators, and restrained blue/violet accents.

IMPORTANT LIMITATION
The GitSkins /api/section/stack card shown in your screenshot is an automatically generated language-spectrum card. It reports languages detected from public repository code; it is not a configurable skills-list component. Its documented examples expose theme/style options, but do not document a parameter for inserting arbitrary categories and tools. Therefore this custom SVG keeps the same visual language while allowing your full stack to appear in one panel.

INSTALL
1. Upload assets/tools-behind-the-work.svg to the assets folder in whiskerwolf/whiskerwolf.
2. In README.md, remove the old GitSkins Technology Spectrum image AND the separate technology lists below it.
3. Paste the contents of README-SNIPPET.md in that location.
4. Commit both files to main.
